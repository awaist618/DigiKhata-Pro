# DigiKhata Pro 📱

**DigiKhata Pro** is a production-ready, high-performance bookkeeping and digital ledger application built with Flutter and Supabase. It is designed to simplify business management, credit/debit tracking, and financial reporting for small to large scale businesses.

Developed by **Awais Tariq**.

## 🚀 Key Features

### 🔐 Authentication & Security
- Secure Login/Registration with Supabase.
- Biometric (Fingerprint) authentication.
- Auto-logout for enhanced data privacy.

### 💼 Business Management
- Multi-business support within a single workspace.
- Linked businesses for seamless collaboration.
- Real-time cloud sync and daily automated backups.

### 📊 Financial Ledger
- **Cash In (Credit)** and **Cash Out (Debit)** tracking.
- Interactive Customer and Supplier ledgers.
- Tag-based transaction categorization with custom colors.
- Image receipt attachments for every transaction.

### 🛡️ Super Admin Panel
- **Analytics Dashboard**: Monitor platform-wide revenue and user growth.
- **System Configuration**: Real-time maintenance mode toggle.
- **Policy Management**: Live editing of Terms and Privacy policies.
- **Reporting Engine**: Export detailed Excel reports for User Growth, Business Activity, and Transactions.

### 🌍 UX & Internationalization
- **Dual Language Support**: Full English and Urdu localization.
- **Theme Engine**: Professional Dark and Light mode support.
- **Fast Performance**: Minified APK (< 25MB per ABI) for low-end device compatibility.

## 🛠️ Technology Stack
- **Frontend**: Flutter (Material 3)
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- **State Management**: Riverpod
- **Local Database**: Drift (SQLite)
- **Local Auth**: Biometric authentication
- **Analytics**: fl_chart
- **Reports**: excel, share_plus
